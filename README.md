# Student Expense Tracker

A beginner-friendly Flask and SQLite money diary for recording student expenses.

## Run locally

1. Optional but recommended: create and activate a virtual environment.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the app:

   ```bash
   python app.py
   ```

4. Open **http://127.0.0.1:5000** in your browser.

The local `expenses.db` file is created automatically on first run. No login, API key, cloud database, or external service is needed.
